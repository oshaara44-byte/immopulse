# ImmoPulse — Parcours de conversion

## Objectif

Transformer progressivement un visiteur en utilisateur actif, puis en client payant, sans promesse trompeuse ni collecte abusive de données.

## Étape 1 — Découverte

Le visiteur découvre ImmoPulse par :

- recommandation ;
- prospection directe ;
- contenu organique ;
- publicité ;
- partenaire ;
- démonstration.

### Message principal

> ImmoPulse aide les professionnels de l’immobilier à savoir quels prospects relancer et à mieux suivre leurs opportunités.

## Étape 2 — Compréhension

Le visiteur consulte :

- la promesse ;
- les fonctionnalités ;
- les forfaits ;
- les langues ;
- les règles de l’essai ;
- les limites ;
- la politique de confidentialité.

## Étape 3 — Inscription

Le visiteur crée un compte avec :

- nom ;
- email ;
- mot de passe ou fournisseur d’authentification ;
- rôle ;
- langue ;
- acceptation des conditions nécessaires.

## Étape 4 — Choix du mode d’essai

### Découverte

- 14 jours gratuits ;
- sans paiement préalable ;
- accès limité ;
- objectif : découvrir.

### Complet

- 14 jours gratuits ;
- choix d’un forfait ;
- engagement de paiement du premier mois ;
- facturation transparente après l’essai si non annulé ;
- accès plus complet ;
- accompagnement prioritaire.

## Étape 5 — Activation

L’utilisateur doit :

1. Compléter son profil.
2. Choisir agent, agence ou particulier.
3. Ajouter un bien ou créer une alerte.
4. Ajouter un prospect ou définir ses critères.
5. Voir une première action ou une première correspondance.

## Étape 6 — Première valeur

### Agent

- un bien publié ;
- un prospect associé ;
- une action recommandée ;
- une relance préparée.

### Particulier

- une alerte enregistrée ;
- une préférence de notification ;
- une première correspondance ou confirmation.

## Étape 7 — Utilisation pendant l’essai

Le système accompagne l’utilisateur par :

- message de bienvenue ;
- aide à l’activation ;
- rappel de fonctionnalités ;
- notification des actions ;
- rappel des jours restants ;
- support.

## Étape 8 — Conversion

Avant la fin de l’essai :

- rappeler la date d’expiration ;
- afficher les forfaits ;
- montrer les fonctions utilisées ;
- montrer les données conservées ;
- présenter le prix ;
- expliquer les conditions ;
- permettre l’annulation ou la poursuite.

## Étape 9 — Abonnement

L’utilisateur :

1. choisit un forfait ;
2. confirme le prix ;
3. valide le paiement ;
4. reçoit une confirmation ;
5. accède aux fonctions du forfait ;
6. peut gérer son abonnement.

## Étape 10 — Après conversion

Le système :

- active le forfait ;
- applique les limites ;
- conserve les données ;
- envoie les notifications nécessaires ;
- affiche les factures ;
- permet l’export et la suppression.

## Relances

### Jour 0

Bienvenue et guide de démarrage.

### Jour 3

Aide pour ajouter un premier bien ou créer une alerte.

### Jour 7

Rappel de la valeur et des fonctions principales.

### Jour 11

Présentation des forfaits et de la fin prochaine de l’essai.

### Jour 13

Rappel transparent de l’expiration et du paiement éventuel.

### Jour 14

Information sur l’expiration et les options disponibles.

## Règles de conformité

- Consentement enregistré.
- Pas de paiement caché.
- Date de facturation visible.
- Annulation claire.
- Données exportables.
- Suppression possible.
- Messages marketing séparés des messages de service.
- Aucun visiteur anonyme présenté comme prospect identifié.
