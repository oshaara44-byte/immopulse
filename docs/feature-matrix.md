- Oui : inclus.
- Limité : inclus avec une limite de volume ou d’usage.
- Non : non inclus.
- Option : disponible contre paiement ou configuration séparée.

## Règles

- Les fonctionnalités doivent respecter le forfait choisi.
- L’essai complet peut ouvrir temporairement les fonctions du forfait sélectionné.
- Les fonctions non incluses peuvent être visibles mais verrouillées.
- Aucun accès ne doit contourner les limites côté serveur.
- Toute limite doit être expliquée à l’utilisateur.
- Les données restent exportables, même après expiration.
